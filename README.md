# JobTrack – Job Application Tracker

A simple full-stack React + Express mini project for CS3301 CIE-2.

## Selected tutorial
GreatStack – Build Full Stack Job Portal App with React JS, Express JS, Node JS, Clerk Auth and Sentry (YouTube):
https://www.youtube.com/watch?v=VIIaMCBeQF0

The tutorial is used as the reference for the job-portal concept. This academic version intentionally simplifies the scope for easy implementation and viva explanation while retaining the required React and Express concepts.

## Features
- Job listing and details
- Apply for a job using a controlled form
- Application tracking with status
- Search and location filtering
- Dashboard statistics
- React Router navigation
- Express REST API
- Responsive CSS
- Class component on About page

## Run
### Server
cd server
npm install
npm start

### Client
cd client
npm install
npm run dev
